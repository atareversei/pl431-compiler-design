# Solutions to Programming Language Pragmatics Exercises

This repository contains my personal solutions to selected exercises from  
**Programming Language Pragmatics** by Michael L. Scott.

**Important:**  
The original exercise text is _not_ included due to copyright restrictions.  
Instead, each exercise is listed with a **paraphrased description** followed by my solution.

These solutions are intended for study, reference, and discussion.

## Structure

- `<chapter-number>/`  
  Contains one file per exercise (e.g., `01.md`, `02.md`, …) with:
  - a paraphrased exercise description
  - my detailed solution
