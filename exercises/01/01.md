# Types of Errors in Programs

Give one small program or expression that demonstrates each of these categories of errors:

- a tokenization/lexical error
- a syntax/grammar error
- a static semantic error caught before running
- a runtime semantic error
- an error that cannot be detected by the compiler or runtime system
Explain briefly why each fits the category.
