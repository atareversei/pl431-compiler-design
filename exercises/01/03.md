# Advantages of Interpretation Over Compilation

List the major benefits of executing a program by interpreting it directly (instead of compiling to machine code).

---

Like any other topic in the computer science, every decision is faced with a tradeoff and the decision between compiled and interpreted languages is not an exception. I believe there are some advantages to interpreted languages which make them a valuable option for certain scenarios.

1. Portability
   An interpreter or virtual machine provides a stable, machine-independent execution environment. As long as the interpreter is implemented on each platform, the same program can run everywhere without recompilation. This greatly reduces the cost of supporting multiple architectures. Though some modern compiled languages like Rust and Go make porting very straightforward compared to traditional languages.
2. Flexibility
   For purposes like writing a few-hundred-line script file, prototyping a simple mathematical equation, or writing a simple function that executes on the event of a button click, it is often better to make use of interpreters that have dynamic typing, dynamic linking, and interactive REPLs. These features allow programmers to experiment, prototype, and iterate quickly.
3. Accessibility
   Interpreted environments require little setup and allow incremental execution, making them ideal for beginners, domain experts, and non-specialists who need to write small programs without worrying about compilers, build systems, or platform-specific details.
4. Better debugging and better runtime feedbacks
   An interpreter has complete control of execution and can provide detailed error messages, tracing, breakpoints, and other debugging facilities.
