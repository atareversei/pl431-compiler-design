# 1.4 Rewriting and Comparing GCD Algorithms

An example shows a GCD algorithm based on repeated subtraction. Rewrite it using modulus instead. Correct any errors that may appear. Then compare the performance of the two versions and explain under what conditions the modulus-based version is faster.

---

The correct answer is:

```c
int main() {
  int i = getint(), j = getint();
  while (i != j) {
    if (i > j) {
      int r = i % j;
      if (r == 0) i = j
      else i = r
    }
    else {
      int r = j % i;
      if (r == 0) j = i
      else j = r
    }
  }
  putint(i);
}
```

I tested and benchmarked these two solutions in Golang. The modulo solution was 3 times in magnitude faster than the the subtraction code, especially in cases where a number is much larger than the other that result in larger duration to converge towards a GCD.
