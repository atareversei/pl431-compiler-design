# 1.6 Comparing Traversals: Interpretation vs Code Generation

Both interpreters and code generators walk the abstract syntax tree (AST).

Explain:

- In what ways are their tree traversals similar?
- How do they differ in purpose, what each produces, and what kinds of information each must maintain?

---

## Similarities

- Both operate on the same intermediate representation (the syntax tree) where each node is a specific operation (e.g. assignment or arithmetic).
- Both must respect program structure and evaluation order.

## Differences

- Interpretation executes the program directly during traversal and result is produced immediately at runtime.
- Code generation traverses the tree to emit target code (assembly, machine code, bytecode) which is just another program to be executed later, not the final computation.
