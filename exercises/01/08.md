# 1.8 Accuracy and Limitations of make‑style Dependency Tracking

The make tool decides whether to rebuild a file by comparing timestamps against its declared dependencies. Evaluate how accurate this mechanism is. Describe conditions where:

1. unnecessary recompilation happens, and
2. required recompilation is missed because dependencies are incomplete or incorrect.

---

This form of dependency management could get out of sync very easily.

- Scenario 1: File B depends on file C and the programmer has forgotten to include the dependency in make configuration. Now if file C changes, the make utility won't notice that it needs to recompile file A.
- Scenario 2: Formatting the code (adding newlines, deleting extra lines, breaking lines, and fixing indentation for better readability), rearranging the code (moving functions and variables around without changing the semantics of the file), and adding documentation comments in file B would cause the make utility think that a recompile is necessary for file A.
