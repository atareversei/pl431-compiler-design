# Language Design and Compiler Construction

**Course:** PL431 – Language Design  
**Focus:** Programming languages and compiler construction  
**Contents:** Lox interpreter and VM, SQL engine, typed functional language

## Projects

- **Lox Interpreter** – implementation of the Lox programming language
- **Mini SQL Engine** – query parsing and execution
- **Typed Functional Language (OCaml)** – minimal language with static type system

## Topics

Lexing and parsing, abstract syntax trees, interpreters, type systems, functional programming, and language semantics.

## Technologies

Rust · C · OCaml
